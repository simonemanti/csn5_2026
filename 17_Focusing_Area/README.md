# PRISM focusing-area figure and vignettes

## Overall figure: four arrangements

**Selected layout: v2 (linear).** The latest refinement flips the simulation
optic so that its concave face points down, increases the crystal icon's inner
margin, uses C8 for CZT, shortens the displayed waveform tails, and sets all
text (including math labels) to **#002a48**. Shared icons keep the other layout
exports consistent with the selected version.

The editable TikZ layouts are `v1_Focusing_Area.tex` through
`v4_Focusing_Area.tex`. Every page is exactly **224.2 × 70 mm**.
All four use the workflow **SIMULATION → CRYSTAL → XAS → CZT → XANES**:
model the instrument, select the energy, excite the sample, detect fluorescence
and reconstruct the near-edge spectrum. Four TikZ Stealth arrows connect the
circles without crossing their borders. The setup rendering is omitted.

| Version | Arrangement |
|---|---|
| v1 | Clockwise pentagon around PRISM |
| v2 | Linear, left to right, with PRISM above |
| v3 | Two rows: three stages above, then two below, in a serpentine path |
| v4 | Left-to-right arch, with PRISM below |

Colours use the Matplotlib cycle: **SIMULATION C0,
CRYSTAL C1, XAS C2, CZT C8, XANES C4**. Backgrounds mix the base colour with
50% white; objects use saturated/darker colours. XAS/XANES retain the original
vector paths and lettering; generated copies recolour the backgrounds and
XAS electron. The original SVGs are preserved.

Run `make` or `make focusing` to produce all four versions in PDF, SVG
and PNG (3363 × 1050 pixels by default, transparent background).
`v0_Confronto.png` is a labelled comparison of all four, produced with Pillow.
For a single version, use e.g. `make v2_Focusing_Area.png v2_Focusing_Area.pdf`.
To export at another resolution:
`make -B focusing FOCUSING_PNG_WIDTH=4484`.
The SVG contains only vector text/drawings; the setup rendering is removed.
The PDF is an intermediate output and is also suitable for LaTeX inclusion.

Sources used in the composition:

- XAS/XANES: `assets/XAS_C2.svg` and `assets/XANES_C4.svg`, generated by the
  Makefile from the existing `1_XAS/XAS.svg` and `2_XANES/XANES.svg`.
- CRYSTAL: the calculated ideal-crystal Ge(220) curve in
  `4_Crystal/reflectivity_Ge220.dat`, plus a shallow, smooth wafer drawn in TikZ
  without a lattice grid.
  The Ge(220) curve is illustrative; it does not change PRISM's Ge(880) design.
- CZT: a schematic **20-anode array**, drawn directly in TikZ with a C8
  sensor body and contrasting electrodes. Waveforms are black; the check mark
  and cross use C8 mixed with 40% black. The two waveforms display the first
  66% of the record, retaining the original time spacing and amplitudes.
  The full data remain in `5_Pulse_Shape/waveforms.dat`, with their original
  independent normalization; their provenance is documented below.
- SIMULATION: a resolved three-ray bundle from an aperture through an optic to
  a segmented detector, plus a binned response histogram and smooth envelope.
  Neither is a simulated performance result.

Composition coordinates and labels are in each numbered TeX. Shared icon
drawings, colours and styles are in `focusing_common.tex`, so icon edits apply
to every layout at once.
`make vignettes` retains the original workflow for all five separate icons.

## Build and edit

Run `make vignettes` here, or `make` within an individual TikZ vignette folder.
Requires lualatex with TikZ/standalone/fontspec and the installed Arial font, pdftocairo and Inkscape.
Use `make -B PNG_WIDTH=2400` for a different PNG resolution.
`make clean` removes only intermediate `.build` folders.
Edit the `.tex` sources to change the drawings. Curves are embedded as vector
coordinates; the `.dat` files preserve the underlying numeric values.
The SVGs are vector exports with outlined text.
The root XAS.svg/XANES.svg originals and the Cathode reference are preserved.
Previous versions are in `.previous_v1` through `.previous_v5`.

## CZT

Ball-and-stick style inspired by `3_CZT/Cathode/v2_LiCoO2.png`.
The structure is rebuilt for zinc-blende CZT, not copied from the LiCoO2 lattice.
FCC cation sites: (0,0,0), (0,1/2,1/2), (1/2,0,1/2), (1/2,1/2,0).
Te sites: those positions shifted by (1/4,1/4,1/4).
The finite 28-atom cluster joins unlike sites at sqrt(3)/4 lattice units.
Zn substitutes selected Cd sites for illustration; no detector composition x
or measured lattice parameter is asserted. XYZ coordinates are in lattice units.
Jmol/CPK atom colors: Cd #FFD98F; Zn #7D80B0; Te #D47A00. Perspective is orthographic with shaded spheres.
Crystallographic reference: https://www.mdpi.com/2073-4352/8/1/26

## Crystal

### Curve in the overall figure

`4_Crystal/s1_reflectivity_icon.py` generates `reflectivity_Ge220.dat` using
the established functions in `../02_Lower_Reflection/s1_reflection.py`.
It uses the supplied OASYS screenshot's settings: flat perfect Ge(220),
10,000 eV, 7 mm thickness, symmetric Bragg diffraction, sigma polarization,
and an angular range of ±100 microradians around the corrected Bragg angle.
The calculation uses crystalpy's Guigay thick-crystal implementation.
No normalization, smoothing or hand adjustment is applied to the curve.

Regenerate it from this folder with:

```bash
conda run -n shadow4-mosaics python 4_Crystal/s1_reflectivity_icon.py
```

The icon omits numeric ticks and the reflection index. Its purpose is to show
the reflectivity profile clearly, not to predict the response of a bent
Ge(880) assembly. The shallow wafer is a schematic shape, without a lattice grid.

### Original separate vignette

Bent wafer with a schematic atomic surface grid, inspired by
`../3_Simulations/O-2094 subsrate for Von Hamos analyzer 50x25 R206.pdf`.
That drawing specifies an aluminium substrate, 52 x 27 mm, R=206 mm.
The vignette exaggerates curvature. The surface grid is a visual symbol,
not a resolved Ge(880) atomic termination or a scaled mechanical model.

The asymmetric reflectivity curve is calculated, not hand-drawn: existing
`../02_Lower_Reflection/s1_reflection.py`, diffraction_setup(8,8,0,1e-3),
reflectivity_profile at 25500 eV about the corrected Bragg angle.
It is (R_sigma + R_pi)/2 from crystalpy's Guigay thick-crystal calculation,
for a flat perfect Ge(880) crystal, 1 mm thick. The displayed domain is +/-4 urad;
the ordinate is intrinsic reflectivity. Axes omit numerical ticks for icon use.
This is an ideal-crystal illustration: bending, strain and beam divergence are
not included, so the curve does not predict the response of the bent assembly.
Raw plotted values are in `4_Crystal/reflectivity.dat`.

## Pulse Shape

Real events selected by `../13_CZT/s1_plot.py`:
- check mark: index 3428, PSA prediction 1, num_peaks=1;
- cross: index 19518, PSA prediction 0, num_peaks=2.

Source HDF5 (current location):
`/home/smanti/WORK/SIDDHARTA/CZT/09_CZT_BTF/DATA/20261802_102216_Snap_Bin_file_ch0.h5`.
Predictions verified against `../13_CZT/max_values_test.h5`.
Each waveform is baseline-subtracted using its first 32 samples and normalized
to its maximum absolute amplitude. All 656 samples are retained in the data,
without smoothing; the overall figure crops the display to x <= 0.66 to shorten
the long final plateaus. The separate pulse-shape vignette retains the full record.
The horizontal coordinate is a fraction of the full acquisition window, with
no numeric time scale claimed. All four overall figures use black traces and
dark C8 acceptance symbols. The separate vignette retains its original style.
Numeric values are saved in `5_Pulse_Shape/waveforms.dat`.
